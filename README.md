# Online Job Portal

A full-stack job portal built with React, Express, and MongoDB.

## Setup

### Backend
1. Go to `api/`
2. `npm install`
3. Create `.env` and add `MONGO_URI`
4. `node index.js`

### Frontend
1. Go to `client/`
2. `npm install`
3. `npm run dev`

## Tech Stack
- **Frontend**: React, Tailwind CSS
- **Backend**: Express, Node.js
- **Database**: MongoDB
- **Hosting**: Vercel
